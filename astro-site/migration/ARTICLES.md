# AK-006 — Legal Insights migration

All articles in the existing registry are rendered from their original HTML at build time. This transitional adapter deliberately retains the original article hero, body, special Udyam layout, visible dates, citations and judgment download links; no legal prose is rewritten. Existing explicit heading IDs are retained; missing IDs are generated. Generated IDs require fragment-parity review against the old client runtime. All existing image and judgment assets are copied unchanged by blob SHA. The static directory includes every article, filters by category and searches titles, excerpts and tags; JavaScript progressively reveals twelve at a time. Related articles are selected by shared tags/category. Homepage uses the same registry at build time. Practice links now route to preview articles. Unmigrated core pages still link to production. Metadata and JSON-LD are retained from original source, with preview noindex. No real analytics or ads enabled. Astro native content collections/Markdown conversion and RSS/sitemap automation are deferred to AK-007 to avoid introducing content loss during migration. Final browser, source parity, link and HTTP tests remain required. No main or DNS changes.

Generated heading slugs follow the previous direct-rail algorithm (ampersand expansion, 80-character maximum, prefix for numeric starts); explicit IDs are preserved. Full fragment parity remains a release test.
