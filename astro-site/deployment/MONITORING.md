## Free dashboard checklist
- Google Search Console (https://search.google.com/search-console): Performance > Search results (clicks, impressions, CTR, position; compare pages and queries); Indexing > Pages (filter to submitted sitemap where available); Sitemaps; URL Inspection for priority changed routes; Manual actions and Security issues; Core Web Vitals. Record user-declared vs Google-selected canonical when inspection is available.
- Bing Webmaster Tools (https://www.bing.com/webmasters/): Search Performance, Site Explorer/URL Inspection, Sitemaps, and AI Performance if available. Review the recorded Delhi MSEFC article warning and alt notice; avoid treating historical warnings as fresh findings without current evidence.
- GA4 (https://analytics.google.com/) and GTM (https://tagmanager.google.com/): verify consent-gated sessions and acquisition, then the six allowlisted event names: phone_click, email_click, whatsapp_click, case_enquiry_click, contact_click, enquiry_submit. Distinguish contact clicks from successfully submitted enquiries. Confirm enquiry_submit is recorded after successful delivery, configured as a key event if approved, and has no private enquiry data or sensitive URL parameters. Test allow, decline and withdrawal in a real browser with network inspection; use synthetic data only. Do not send a live test without owner approval.
- Cloudflare and EmailJS: review security events, error rates, DNS/TLS, quota and delivery failures. Field CWV may be unavailable at low traffic; label unavailable data rather than infer it from lab Lighthouse.
